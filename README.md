# 看书宝 Mac

豆包实时语音学习助手，支持 USB 摄像头预览、按问题抓帧看题、作业批改、文字对话历史与明确记忆管理。

## 运行

- macOS 13 或更高版本；当前发布的启动器为 Apple Silicon 构建。
- 安装 Python 3.10 或更高版本、FFmpeg（包含 ffplay）。使用 Homebrew 可执行 `brew install python ffmpeg`。
- 解压完整运行包，保持 `看书宝.app` 与 `app` 文件夹在同一目录。不要单独移动 `.app`。
- 双击 `看书宝.app`。首次使用需允许摄像头和麦克风权限。
- 也可在项目目录执行 `bash run.sh`，使用浏览器界面。
- 在设置中填写自己的火山方舟视觉 API Key 和豆包实时语音 API Key；密钥不包含在发布包中。
- 点击“开始通话”开始交流，点击“结束通话”停止。

## 构建

安装 Xcode Command Line Tools 后，执行 `zsh build_app.sh`。本地临时签名不等于 Apple 公证；发布包尚未公证。Intel Mac 需要自行重新构建启动器。

## 数据与隐私

实时通话向豆包语音服务发送麦克风音频；视觉提问和批改向配置的视觉服务上传单帧图片。不是纯离线软件。
密钥保存在本地 `config.json`，文字记忆保存在 `data/memory.sqlite3`。设置中可以关闭、删除和清空记忆。
仓库及发布包不包含个人密钥、照片、日志、缓存和聊天数据库。

## 已知限制

- 当前为测试版。语音播放曾出现无声、断续，结束通话再重开可恢复部分故障，尚未完成稳定性验收。
- 外放时“小豆小豆”打断会受自身回声影响，可能自问自答或截断播报；推荐耳机，或关闭口令打断及普通插话。
- 看题为按关键词抓单帧，不是连续视频理解；识别与回答可能有错误，批改不能仅凭已有对勾判定。
- 视觉请求增加网络推理延迟，不承诺达到手机豆包视频通话的速度。
- 明确记忆与近期历史会随对话请求发送至模型；不是无限上下文或完整的 Codex 记忆系统。
